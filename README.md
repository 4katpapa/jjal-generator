# 자짤 생성툴

PC 사양을 자동으로 읽어 견적 자짤(사양 카드) 이미지를 만드는 데스크톱 앱입니다.

- 본 툴은 클로드(Claude)를 활용한 바이브코딩으로 제작되었습니다.
- **무료 배포 및 자유 수정 가능** (MIT 라이선스)

## 다운로드

**[⬇ 자짤생성툴v1.3-portable.exe 받기](https://github.com/4katpapa/jjal-generator/releases/latest)**

설치 필요 없이 exe 하나만 받아서 바로 실행하면 됩니다. (Windows 64bit)

> 서명이 없는 프로그램이라 처음 실행할 때 "Windows의 PC 보호" 창이 뜰 수 있습니다.
> **추가 정보 → 실행**을 누르면 됩니다.

## 주요 기능

- Windows 사양 자동 읽기 (CPU / 메인보드 / RAM / 그래픽카드 / SSD)
- 카드 디자인 편집: 테마 12종, 배경(그라디언트·패턴 19종), 테두리 스타일, 그림자
- 이미지 패널(모양 6종·프레임·그림자), 스티커(이모지 48종 + 내 이미지), 텍스트(세로쓰기 지원)
- 밴드 7종(가로 띠·팝업·포스트잇·말풍선·타원·하트·별, 최대 5개)
- 움직임 효과 29종(배경 19 + 테두리 10, 최대 6개 동시)
- PNG(투명 배경) / WebP 내보내기 — 정지는 무손실, 움직임이 있으면 30fps 움짤로 자동 저장
- 디자인 저장/불러오기, 실행 취소/다시 실행(Ctrl+Z/Y)

## 변경 이력

### v1.3 — 저장물 검은 테두리 해결
- **빛번짐을 카드 안쪽으로 제한** (기본 켜짐) — 테두리 글로우나 테두리 움직임 효과가 카드 밖으로 번지면 그만큼 투명 여백이 생기고, 그 여백이 디시인사이드 등 일부 뷰어에서 **검은 테두리**로 보이던 문제를 고쳤습니다. 켜두면 저장 크기가 항상 카드 크기와 정확히 같아집니다.
- **저장 배경 선택** (투명 / 흰색 / 카드 배경색) — 둥근 모서리 바깥까지 채웁니다. 다크 모드가 있는 곳에 올린다면 '카드 배경색'이 가장 자연스럽습니다.

### v1.21 — 모바일 UI 대응
- **좁은 화면 전용 레이아웃** — 미리보기가 위에 고정되고 컨트롤 패널이 그 아래에서 스크롤됩니다. 값을 조절하면서 결과를 바로 볼 수 있어요.
- **터치 조작 지원** — 이전에는 마우스에서만 동작하던 드래그(이미지·텍스트·스티커 이동, 색상 고르기)가 손가락으로도 됩니다.
- **크게 보기(🔍)** — 미리보기 아래 버튼을 누르면 화면 전체로 확대됩니다. 가로로 긴 카드는 자동으로 눕혀서 보여줘, 폰 세로 화면 기준 약 2배 크게 볼 수 있어요.
- **출력 크기·배율 표시** — 미리보기 아래에 `850 × 300 px  44%` 처럼 실제 저장될 크기와 현재 축소 배율이 표시됩니다.
- 좁은 화면에서는 툴바 버튼이 아이콘으로 바뀌어 자리를 덜 차지합니다.
- 입력칸을 눌렀을 때 화면이 확대되던 문제(iOS), 버튼이 눌린 채로 남던 문제를 고쳤습니다.

### v1.2 — WebP 정지 이미지 · 이미지 화질
- 움직임이 없어도 WebP로 저장(무손실), 첨부 이미지 단계적 축소로 모아레 감소, 1:1 출력, 사양 라벨/값 굵게 옵션

## 실행 방법 (소스에서)

1. [Node.js](https://nodejs.org) LTS 버전 설치 (v18 이상)
2. 이 폴더에서 터미널(명령 프롬프트/PowerShell)을 열고:

```
npm install     # 필요한 라이브러리 설치 (최초 1회)
npm start       # 앱 실행
```

## 포터블 exe로 빌드

```
npm run dist
```

`dist\자짤생성툴v1.3-portable.exe` 가 생성됩니다.

> 참고: 빌드 중 `winCodeSign` 압축 해제 오류(심볼릭 링크 권한)가 나면,
> Windows 설정에서 개발자 모드를 켜거나 관리자 권한 터미널로 한 번 빌드하면 됩니다.

## 폴더 구조

```
main.js          앱 진입점 (창 생성, 파일 저장/불러오기 IPC)
preload.js       렌더러에 노출하는 안전한 API 브리지
specReader.js    PowerShell로 PC 사양 읽기
renderer/
  index.html     UI 레이아웃
  style.css      UI 스타일 (라이트/다크 테마)
  app.js         카드 렌더링·편집 로직 전체 (Canvas 2D + WebP 무커)
build/icon.png   앱 아이콘
```

## 데이터 저장 위치

- 저장된 디자인: `%APPDATA%\speccard\designs\*.json`
- 내 사양·최근 색상 등: 앱 내부 로컬 저장소

앱을 완전히 삭제하려면 위 폴더도 함께 지우면 됩니다.
