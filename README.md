# 자짤 생성툴

PC 사양을 자동으로 읽어 견적 자짤(사양 카드) 이미지를 만드는 데스크톱 앱입니다.

- 제작: 디시인사이드 데스크탑 갤러리 · **정신안차려?**
- 본 툴은 클로드(Claude)를 활용한 바이브코딩으로 제작되었습니다.
- **무료 배포 및 자유 수정 가능 — 제작자 이름만 남겨주세요.**

## 다운로드

**[⬇ 자짤생성툴v1.1-portable.exe 받기](https://github.com/4katpapa/jjal-generator/releases/latest)**

설치 필요 없이 exe 하나만 받아서 바로 실행하면 됩니다. (Windows 64bit)

> 서명이 없는 프로그램이라 처음 실행할 때 "Windows의 PC 보호" 창이 뜰 수 있습니다.
> **추가 정보 → 실행**을 누르면 됩니다.

## 주요 기능

- Windows 사양 자동 읽기 (CPU / 메인보드 / RAM / 그래픽카드 / SSD)
- 카드 디자인 편집: 테마 12종, 배경(그라디언트·패턴 19종), 테두리 스타일, 그림자
- 이미지 패널(모양 6종·프레임·그림자), 스티커(이모지 48종 + 내 이미지), 텍스트(세로쓰기 지원)
- 밴드 7종(가로 띠·팝업·포스트잇·말풍선·타원·하트·별, 최대 5개)
- 움직임 효과 29종(배경 19 + 테두리 10, 최대 6개 동시)
- PNG(투명 배경) / WebP(움짤, 30fps·풀컬러·투명 배경) 내보내기 — 3배 슈퍼샘플링
- 디자인 저장/불러오기, 실행 취소/다시 실행(Ctrl+Z/Y)

## 실행 방법 (소스에서)

1. [Node.js](https://nodejs.org) LTS 버전 설치 (v18 이상)
2. 이 폴더에서 터미널(명령 프롬프트/PowerShell)을 열고:

```
npm install     # 필요한 라이브러리 설치 (최초 1회)
npm start       # 앱 실행
```

## 포터블 exe로 빌드

```
npm run dist
```

`dist\자짤생성툴v1.1-portable.exe` 가 생성됩니다.

> 참고: 빌드 중 `winCodeSign` 압축 해제 오류(심볼릭 링크 권한)가 나면,
> Windows 설정에서 개발자 모드를 켜거나 관리자 권한 터미널로 한 번 빌드하면 됩니다.

## 폴더 구조

```
main.js          앱 진입점 (창 생성, 파일 저장/불러오기 IPC)
preload.js       렌더러에 노출하는 안전한 API 브리지
specReader.js    PowerShell로 PC 사양 읽기
renderer/
  index.html     UI 레이아웃
  style.css      UI 스타일 (라이트/다크 테마)
  app.js         카드 렌더링·편집 로직 전체 (Canvas 2D + WebP 무커)
build/icon.png   앱 아이콘
```

## 데이터 저장 위치

- 저장된 디자인: `%APPDATA%\speccard\designs\*.json`
- 내 사양·최근 색상 등: 앱 내부 로컬 저장소

앱을 완전히 삭제하려면 위 폴더도 함께 지우면 됩니다.
