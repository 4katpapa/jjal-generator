# 자짤 생성툴 2.0

Windows PC 사양을 읽고, 이미지·문구·도형을 배치해 명함형 사양 카드를 만드는 Electron 데스크톱 앱입니다.

- Claude Code와 Codex를 이용해 제작했으며, 2.0에서 편집 구조와 사용 경험을 전면 개편했습니다.
- 무료 배포 및 자유 수정 가능(MIT). 재배포할 때 제작자 이름을 남겨 주세요.

## 2.0 핵심 기능

- **작업 중심 UI**: 내용·규격 / 사양 패널 / 이미지 / 배경·테두리 / 텍스트·요소의 5개 작업 탭
- **안전한 자동 사양 읽기**: CPU, 메인보드, RAM 규격·부품번호·속도, GPU, NVMe/SSD/HDD를 읽고 적용 전 결과 확인
- **수동 입력 보호**: 자동 감지는 사용자가 이미 적은 값을 덮어쓰지 않으며, 같은 종류의 추가 장치는 기존 항목 옆에 배치
- **실용적인 사양 배치**: 1·2열 전환, 행 기준 분할 지점, 열·항목·라벨-값 간격과 정렬, 값 입력창의 Enter 줄바꿈, 패널 크기에 맞춘 자동 축소·줄바꿈
- **직접 조작 패널 편집**: 이미지·사양 패널 안쪽은 이동, 네 변은 가로·세로 크기 변경, 네 모서리는 회전으로 구분하고 정확한 X/Y는 숫자로 보정
- **직접 조작 사진 크롭**: 패널 이동과 내부 사진 크롭 모드 분리, 중앙 정렬·초기화, 크기·회전·좌우 반전·투명도·색 보정
- **표현 확장**: 텍스트 입력, 이미지/이모지 스티커, 도형, 미리보기에서 직접 위치를 옮기는 배경 이미지와 세밀한 요소 그림자·패턴·테두리
- **절제 가능한 모션**: 효과별 켜기, 배경/내용 위/테두리 층, 방향, 투명도, 순서, 미리보기 일시정지, 최대 8개
- **상단 출력과 사전 점검**: 미리보기 우측의 PNG/WebP 버튼에서 경계·배경·배율·대표 프레임·길이·FPS·품질·예상 메모리를 확인
- **저장 안전성**: 디자인 썸네일, 저장 전 이탈 확인, 자동 복구본, 휴지통 삭제, 디자인 이름 옆의 `.speccard` 파일 열기·백업
- **사양 프로필**: 여러 PC 사양 묶음을 디자인과 별도로 저장·불러오기·관리

자동 감지는 Windows가 공개하는 정보만 사용합니다. 전원공급장치와 케이스처럼 운영체제가 신뢰성 있게 알 수 없는 항목은 빈 값을 임의로 만들지 않습니다.

## 실행 방법

Node.js 18 이상이 필요합니다.

```powershell
npm install
npm start
```

검증:

```powershell
npm run check
```

포터블 실행 파일 빌드:

```powershell
npm run dist
```

결과물은 `dist\자짤생성툴v2.0-portable.exe`입니다.

## 데이터 위치

- 저장된 디자인: `%APPDATA%\speccard\designs\*.json`
- 자동 복구본: `%APPDATA%\speccard\recovery-v2.json`
- 사양 프로필, 최근 색상, UI 설정: Electron 로컬 저장소
- 사용자가 내보낸 `.speccard`, PNG, WebP: 저장 대화상자에서 고른 위치

디자인 삭제는 즉시 영구 삭제하지 않고 Windows 휴지통으로 보냅니다. 2.0 저장본은 `schemaVersion: 2`를 사용하며, 1.x 디자인은 불러올 때 호환 변환됩니다.

## 폴더 구조

```text
main.js                 창, 파일 저장, 자동 복구, 클립보드 IPC
preload.js              렌더러에 노출하는 최소 API
specReader.js           Windows 사양 감지와 정규화
renderer/index.html     작업 중심 UI
renderer/style.css      모듈러 스펙 벤치 테마와 반응형 레이아웃
renderer/v2-core.js     2.0 상태 정규화·병합·배치 순수 함수
renderer/app.js         Canvas 편집기와 PNG/WebP 출력
tests/                   사양 감지·2.0 상태/배치 회귀 테스트
```

## 변경 이력

### v2.0.0 — 편집 경험 전면 개편

- 기능 번호를 따라가던 긴 패널을 작업 목적별 5개 탭으로 재구성
- 이미지 스크롤식 조정을 직접 조작+숫자 입력 방식으로 교체하고 패널/크롭 조작을 분리
- 2열 사양의 분할 행·열 간격·정렬을 명확히 분리하고, 값 입력창의 Enter 줄바꿈을 그대로 반영
- 사양 목록을 패널 컨테이너 안에서 자동 축소·줄바꿈·클리핑하고, 일괄 색상 적용 중인 행별 색상에는 잠금 표시와 호버 안내를 추가
- 이미지·사양 패널의 네 변 크기 조절과 네 모서리 회전을 분리하고, 회전 전용 초기화와 사진 크롭 모드를 추가
- 카드 그림자와 행 숨김·레이어 관리처럼 결과보다 복잡도와 여백을 늘리던 기능 제거
- 이미지·사양 패널·텍스트·도형 그림자를 색·불투명도·블러·X/Y로 세분화
- 효과의 층·순서·투명도·방향·일시정지와 출력 경계 선택을 추가해 난잡함과 불필요한 여백을 제어
- 배경 이미지 직접 드래그, 상단 외부 프로젝트 파일 도구, 다중 사양 프로필, 자동 복구 추가
- RAM/저장장치/GPU 감지를 보수적으로 보강하고 알 수 없는 PSU·케이스 값을 추측하지 않도록 수정

### v1.31 이하

빛번짐 제한과 저장 배경, 모바일 UI, WebP 출력, GIF/스티커/텍스트/밴드 편집을 순차적으로 추가했습니다.
