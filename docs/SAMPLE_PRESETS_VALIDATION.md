## 실제 로컬 웹 UI

Codex 브라우저 도구로 http://127.0.0.1:4174/ 에서 확인했습니다. 이 주소는 기존 4173 미리보기 및 공개 사이트의 저장소와 별개입니다.

- 18개 썸네일과 서로 다른 이름을 확인했습니다. 왼쪽과 오른쪽의 사진·닉네임·아이콘·장식 구성을 비교했습니다.
- 오른쪽에는 둥근 세로 사진, 사진 안 배지, 원형 명함, 기울어진 엽서, 가로줄 노트, 하단 픽셀 터미널, 신호 도크, 상단 무대 배너, 원형 오로라 구성을 표시합니다.
- 빈 사진 자리에서도 해당 모양과 프레임을 표시합니다. 실제 사진을 넣은 엽서에서도 사진과 테두리의 회전이 함께 유지됩니다.
- 기존 검증 저장본의 사양 8행·닉네임·사진으로 오른쪽 9개를 모두 미리 보았습니다. 9개 모두 넘침 경고가 없었습니다.
- 갤러리만 둘러본 뒤 닫았을 때 실행 취소는 비활성이며 문서를 변경하지 않았습니다.
- version 2의 15번 라이브 티켓을 열고 사양 위치를 바꾸면 기존 16번 라이브 티켓으로 이동합니다. 새 16번 스테이지 배너로 바뀌지 않았습니다.
- 엽서 서명 적용은 닉네임·8행·사진을 보존했습니다. 한 번의 실행 취소로 이전 라이브 티켓, 다시 실행으로 엽서를 복원했습니다.
- 08번 엽서를 왼쪽으로 옮겨도 08번 이름·하단 서명·사진 회전·아이콘 없음이 유지됐습니다. 16번 배너도 왼쪽으로 옮겨 16번 이름·상단 제목·원형 사진·움직임을 유지했습니다.
- 16번 배너의 움직임을 간편 화면에서 끄고 켰습니다. 선택 창의 재생 중 두 프레임은 달랐고, 일시정지한 두 프레임은 동일했습니다. 확인 후 재생을 복원했습니다.
- `v4-좌우 독립 구성 검증`으로 별도 저장하고 새로고침 후 다시 열었습니다. 16번 이름·사양 왼쪽·움직임 켜짐·8행·닉네임·사진을 복원했습니다. 기존 두 검증 저장본도 별도로 남아 있습니다.
- 관찰한 앱 콘솔 오류·경고는 없었습니다.

## 검증의 한계와 배포 상태

- 이번 수정은 구성·호환·좌우 이동에 집중했습니다. PNG/WebP 내보내기와 모바일 뷰포트는 이전 v4 검증에 이어 이번에는 반복하지 않았습니다. 이전 출력 검증은 브라우저 내 생성까지이며 실제 디스크 파일 재디코딩은 포함하지 않았습니다.
- 저장·재열기는 브라우저 내부 디자인 저장소에서 확인했습니다. 다운로드한 .speccard 파일을 다시 업로드하는 전체 GUI 왕복은 포함하지 않았습니다.
- Windows Electron 네이티브 GUI와 실제 휴대전화 실행은 미확인입니다.
- 소스 버전은 v4.0.0입니다. 패키징·GitHub·공개 Cloudflare 배포 확인은 [릴리스 검증](V4_RELEASE_VALIDATION.md)에 기록합니다.
