## 구현과 데이터

내장 원본은 `assets/backgrounds`에서 빌드의 `resources/backgrounds`로 복사합니다. 개인 이미지는 포터블 런처의 원래 EXE 옆 `Backgrounds` 또는 사용자가 선택한 폴더에서 읽습니다. 두 소스의 같은 이름 파일도 별개 항목으로 인식합니다.

목록을 읽고 원본을 확인할 때 경로·파일 교체·목록 변경을 검사합니다. 내장과 개인 이미지는 읽기 전용으로 취급하며, 필요한 썸네일을 순서대로 읽습니다. 개인 폴더는 개발 저장소의 Git 제외 대상입니다.

선택한 배경 한 장은 기존 디자인 형식에 포함합니다. 앱 버전은 3.0.0이며 저장 스키마와 기존 사용자 저장소 경로를 유지합니다. 이전 아이콘 48개·주변기기 입력과 저장·출력 안정화 구현도 포함합니다. 의존성 잠금 파일은 앱의 두 버전 필드만 변경했습니다.

생성 원본 PNG는 총 189,156,848바이트입니다. 2109×745 77장, 2110×745 16장, 2109×746 7장이며 변환·리사이즈 없이 보관했습니다. 실제 프롬프트와 개별 SHA-256은 `BACKGROUND_GENERATION.json`에 있습니다.

## 확인 범위

네이티브 폴더 선택 창의 반환값은 Electron 검사에서 시험 폴더로 고정했습니다. 파일 읽기·폴더 저장·재선택·재시작, 실제 포터블·압축 해제형의 기본 폴더 동작은 실제 파일로 확인했습니다. 작은 화면은 뷰포트 에뮬레이션이며 물리적인 창 최소 크기 검증은 아닙니다.

다른 PC·DPI·네트워크 드라이브, 2,000장 최대 부하, 실제 전원 차단, 커뮤니티 업로드 후 변환은 미검증입니다. 과학·기술 배경은 장식용 개념 이미지입니다. 글자는 지정 여백에 놓고 글자 색·반투명 사양 패널·흐림·어둡게를 조절해 가독성을 맞춥니다.
