# 웹판 검증 기록

검증일: 2026-09-12~13. 대상은 기존 v3.21(패키지 3.2.1)의 편집 코드를 공유하는 웹판입니다. 로컬 주소 `http://127.0.0.1:4173/`와 공개 주소 `https://jjal-generator.pages.dev/`에서 확인했습니다.

## 자동 검사

- `npm run check`: 기존 검사 61개 및 JavaScript 구문 검사 통과.
- `npm run test:web`: 웹용 검사 12개 통과.
- `npm run build:web`: 정적 웹사이트 생성 완료. 각 배포 파일이 Pages의 파일 크기 제한 이내인지 빌드에서 확인합니다.
- `git diff --check`: 공백 오류 없음.

웹용 검사는 사양 붙여넣기 파싱, HTML 변환과 검색 설정, 브라우저 저장 연결부를 다룹니다. 저장 연결부 검사는 Node VM과 fake-indexeddb를 이용하며, 저장 후 별도 연결에서 다시 읽기·덮어쓰기·삭제, 복구본 처리와 다른 탭의 최신 복구본 보존, 배경 요청과 오래된 목록 거부, 잘못된 프로젝트 거부 등을 확인합니다. 이 결과만으로 실제 브라우저 저장 동작을 입증하지 않으므로 아래 UI 확인을 별도로 수행했습니다.

## 실제 브라우저 확인

Codex 내장 브라우저에서 도구를 통해 버튼·입력란·파일 선택 창을 조작했습니다.

- 첫 화면 초기화, 세 가지 아이콘 시리즈 표시, 기본 편집 화면 렌더링.
- 여러 줄 사양 붙여넣기와 항목 선택, 모니터·키보드 등 주변기기 반영.
- 브라우저 디자인 저장 후 새로고침하고 저장 목록에서 다시 불러오기. 입력한 사양과 배경 유지.
- 배경 164장·18개 분류 표시, 랜덤 선택과 도트풍 분류에서 특정 배경 선택.
- 로컬 PNG를 이미지 패널에 불러온 뒤 실제 미리보기에 표시.
- `.speccard` 형식의 합성 호환성 파일을 파일 선택 창으로 가져오기. 잘못된 프로젝트는 오류를 알리고 기존 편집 내용 유지.
- PNG, 정지 WebP 및 0.5초·15FPS의 움직이는 WebP 생성. 움직이는 출력은 화면에서 8프레임·약 90KB로 완료 표시.
- `.speccard` 백업 생성과 파일명 확인. 각 출력에서 다운로드 링크가 표시됨.
- 1280×720과 390×844 화면 확인. 작은 화면에서 상단 버튼이 넘치던 문제를 수정하고 다시 확인.
- 마지막 작업 후 브라우저의 warning/error 로그 없음.

## 이미지 자산 확인

- 원본 PNG 164장 모두 작업 전 SHA-256과 일치.
- 웹용 배경 164장·썸네일 164장 모두 WebP 디코딩 및 목록에 기록한 규격 확인.
- 세 아이콘 아틀라스는 원본과 알파 및 보이는 RGB 픽셀 일치. 완전 투명 픽셀의 숨은 RGB는 비교에서 제외.
- 원본 배경 합계 312,401,285바이트 → 웹용 배경 23,126,340바이트, 썸네일 1,232,452바이트.
- 웹용 아이콘 합계 2,438,322바이트.

작업 전 백업·해시와 로컬 검사 기록은 프로젝트 내부 `work/web-edition-20260912/`에 보관합니다. 원본 자산과 기존 Windows 배포 파일은 보존했습니다.

## 공개 환경 확인

- Cloudflare Pages의 Linux / Node.js 22.22.0 빌드와 정적 파일 배포 성공. 배경·썸네일·아이콘의 출력 용량이 로컬 빌드와 일치.
- 공개 HTTPS 홈페이지·배경 목록·아이콘 응답 200. 목록은 164장·18개 분류.
- `sitemap.xml` 응답 200, XML 파싱 성공, `loc`는 공개 홈페이지 주소. robots는 크롤링을 허용하며 사이트맵을 안내함. 운영 페이지에 `noindex` 응답 없음.
- 배경 파일의 캐시 헤더는 `public, max-age=31536000, immutable`, 이름이 고정된 파일은 재검증 사용.
- 실제 Chrome에서 사양 4개 붙여넣기, 주변기기 추가, 랜덤 배경 적용, 디자인 저장 확인.
- 사용자가 PNG·WebP·`.speccard`의 바탕화면 저장 성공을 확인. 제공한 파일을 직접 읽어 PNG와 정지 WebP 모두 850×300으로 디코딩됨을 확인하고 PNG의 카드 내용도 시각적으로 확인.
- PNG 478,441바이트, 정지 WebP 304,962바이트. `.speccard`는 193,106바이트로 JSON 파싱 성공, 9행과 내장 배경 데이터 포함.
- 출력 파일의 해시가 일치하는 사본과 검사 결과는 프로젝트 내부 `work/web-deployment-20260912/`에 보관.
- Google Search Console HTML 태그 소유권 확인 완료. 사이트맵 제출 후 가져오기 상태 확인 중.
- `자짤생성툴` 이름 변경 후 웹용 검사 12개와 공개 환경 변수를 적용한 로컬 빌드 통과.

## 남은 확인

- 움직이는 WebP의 생성은 로컬 브라우저에서 확인했으며, 실제 다운로드 파일의 프레임 디코딩은 아직 확인하지 않았습니다.
- 합성 프로젝트 파일은 형식 호환성 확인용입니다. 모든 기존 사용자 프로젝트, Windows 앱과의 실제 파일 왕복, Safari·Firefox 및 실제 휴대전화는 이번 검증 대상에 포함하지 않았습니다.
- 실제 HTTPS 환경의 클립보드 권한, 저장 용량 제한 및 장기간 보관은 아직 확인하지 않았습니다.
- Google의 사이트맵 처리 성공과 대표 페이지 색인은 확인 중입니다. 사이트 공개와 실제 검색 노출은 별개입니다.

현재 운영 설정과 검색 등록 절차는 `docs/WEB_DEPLOYMENT.md`를 참고합니다.
