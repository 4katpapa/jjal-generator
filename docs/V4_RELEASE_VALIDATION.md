실제 공개 주소를 새로고침한 뒤 Codex 브라우저 도구로 확인했습니다.

- 18개 샘플의 서로 다른 이름·썸네일과 새 오른쪽 구성을 확인했습니다.
- 16번 스테이지 배너에 닉네임·사양 8행·검증용 PNG를 넣어 실제 카드가 표시되고 넘침 경고가 없는 것을 확인했습니다.
- 프리셋/직접 만들기 왕복에서 입력값과 움직임 상태가 동일했습니다. 사양 좌우 이동도 16번 이름·스타일을 유지했습니다.
- `v4.0.0 공개 배포 검증 20260913`을 새 디자인으로 저장했습니다. 새로고침 후 저장 목록에서 다시 열어 16번 구성·닉네임·8행·사진·움직임을 복원했습니다.
- 850×300 PNG 생성 완료와 파일명/다운로드 링크를 확인했습니다.
- 움직이는 WebP 850×300·60프레임·약 2,082KB의 생성 완료 안내와 다운로드 링크를 확인했습니다.
- 관찰한 브라우저 warning/error 로그는 없었습니다.
- 출력 검증은 브라우저 내 생성까지입니다. 이번 공개 검증에서 디스크에 저장한 출력 파일을 다시 디코딩하지는 않았습니다.
