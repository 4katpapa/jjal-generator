# 샘플 프리셋과 간편 제작 — v4.0.0

갱신일: 2026-09-13. 소스 구현·로컬 웹 검증·Windows 포터블 패키징을 완료했습니다. 공개 배포 확인은 [릴리스 검증](V4_RELEASE_VALIDATION.md)에 기록합니다.

## 확정 규칙

- 18개 독립 디자인이며 기본 사양 위치는 왼쪽 9개, 오른쪽 9개입니다. 왼쪽 구성을 보존하고 오른쪽에 독립 구성을 적용합니다. 각 샘플은 아이콘·닉네임 위치·패널과 사진 모양·패턴·테두리·움직임으로 구별합니다.
- 이름은 번호와 짧은 특징으로 표시합니다. 효과 수준 분류명은 UI에 표시하지 않습니다.
- 기본 850×300, 사양 1열, 닉네임과 개인 이미지 자리를 갖춥니다. 배경 이미지 파일을 사용하지 않고 색·그라디언트·패턴으로 그립니다.
- 앱과 웹에 나눔고딕 Regular/Bold를 포함합니다. 별도 설치 없이 같은 글꼴로 렌더링합니다.
- 색과 위치는 샘플을 선택한 뒤 조절할 수 있습니다. 프리셋 모드와 직접 만들기는 같은 디자인과 저장·실행 취소 이력을 공유합니다.

## 사용 흐름

1. 상단 **프리셋으로 만들기 → 샘플 고르기**에서 번호·썸네일·아이콘 및 움직임 표시로 선택합니다.
2. 선택한 샘플은 현재 사양·닉네임·이미지로 미리 봅니다. 빈 사양에는 미리보기용 예시를 사용합니다. 선택 미리보기는 움직임을 재생하며 일시정지할 수 있습니다.
3. **이 프리셋 적용** 후 닉네임·사양·이미지, 글꼴·크기·색, 이미지 맞춤·위치, 아이콘, 좌우 및 해당 효과를 간편하게 바꿉니다.
4. **직접 만들기**로 전환하면 현재 디자인을 그대로 세부 조정합니다. 다시 돌아와도 샘플을 재적용하지 않습니다.
5. 기존 저장·백업·PNG/WebP 기능으로 보관합니다. Windows는 자동 사양 읽기, 웹은 직접 입력과 붙여넣기를 지원합니다.

## 배치와 가독성

- 샘플마다 패널/사진 크기와 여백이 다릅니다. 닉네임은 사양 위·아래, 사진 위·아래·안쪽, 카드 전체 상단·하단에 배치합니다.
- 패널 안 제목과 하단 서명에는 사양이 겹치지 않게 공간을 확보합니다. 닉네임을 숨기거나 비우면 그 공간을 사양에 돌려줍니다.
- 빈 사양은 출력에서 생략하되 입력값은 유지합니다. 사양 글자는 기본 20px, 자동 맞춤 최소 16px입니다. 넘침 경고와 **카드 높이 +50px**를 제공합니다.
- 닉네임은 샘플별 24–27px, 한 줄 맞춤 최소 16px입니다. 간편 화면에서 크기를 키우면 제목/서명 공간과 인접 사진 영역도 조정합니다. 긴 이름의 넘침을 경고하며 직접 만들기에서 한 줄 맞춤을 해제할 수 있습니다.
- 사양 위치 전환은 선택한 샘플 ID·이름·효과를 유지하며 닉네임과 사진 종이 프레임을 연결된 패널에 따라 이동합니다. 카드 전체 제목은 제자리를 유지합니다. 사용자 좌표 보정·내용·이미지 방향·회전은 보존합니다. 다른 샘플은 선택 창에서 적용합니다.
- 높이 확장은 하단 서명·사진 캡션·하단 띠를 함께 이동하고 종이 프레임을 늘립니다.
- 사진이 없어도 원형·사선·프레임 등 해당 모양으로 자리 표시를 그립니다. 자리 표시 문구는 출력에 포함하지 않습니다.
- 간편 화면의 사진 내부 드래그로 크롭 위치를 조절할 수 있습니다. 패널 전체 이동·회전·크기는 직접 만들기에서 조절합니다.

## 데이터 보존과 호환

- 샘플 적용은 배치·색·글꼴·프레임을 설정하며, 모든 사양 행과 개별 아이콘/시리즈·닉네임 내용과 표시 여부·사진 원본·파일 연결을 보존합니다.
- 사용자가 추가한 독립 텍스트·도형·스티커·효과는 보존합니다. 샘플 소유 표식이 있는 도형·움직임만 교체합니다. 사용자 ID 충돌도 회피합니다.
- 텍스트 24개, 도형 12개, 효과 8개 한도를 넘으면 기존 데이터를 변경하기 전에 적용 이유를 안내합니다. 기존 요소를 잘라내지 않습니다.
- 적용 전체는 한 번의 실행 취소로 되돌립니다. 모드 변경과 샘플 미리보기·재생·일시정지는 실제 문서와 이력을 변경하지 않습니다.
- 최종 외관과 선택적 preset 메타데이터를 함께 저장합니다. 현재 구성은 메타데이터 version 3입니다. 이전 version 1·2 카드의 외관·이름·효과 정의와 좌우 전환 동작을 보존하며, 파일을 열 때 새 카탈로그로 재생성하지 않습니다.
- 이전 일반 디자인과 알 수 없는 프리셋은 직접 만들기로 엽니다. 저장된 2열 및 사용자 배경을 유지합니다.
- 미리보기는 실제 출력과 같은 Canvas 렌더러를 사용합니다. 선택 시 만든 별도 상태/캔버스를 약 15fps로 재사용하고, 닫거나 탭이 숨겨지면 그리기를 멈춥니다. 동작 줄이기 설정에서는 수동 재생합니다.
