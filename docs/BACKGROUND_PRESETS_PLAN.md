## 내장·개인 배경 사용

내장 100장은 앱을 실행하면 바로 사용할 수 있습니다. **배경·테두리 → 배경 프리셋 둘러보기**에서 전체·내장·개인 배경을 구분하고, 분류·이름으로 검색합니다. 선택 후 **배경으로 적용**하거나 **랜덤 배경 적용**을 누릅니다. 랜덤 적용은 현재 표시하는 목록을 대상으로 합니다.

개인 PNG·JPG·JPEG·WebP는 실행 파일 옆 `Backgrounds`에 넣습니다. 하위 폴더와 임의 파일 이름을 인식하며 JSON 등록은 필요하지 않습니다. **폴더 열기**로 위치를 확인하거나 **폴더 선택**으로 다른 위치를 지정합니다. 개인 폴더를 바꿔도 내장 배경은 그대로 표시합니다.

선택한 배경은 기존 위치·확대·투명도·흐림·어둡게 조절, 실행 취소·다시 실행, 디자인 저장에 연결됩니다. 저장한 한 장은 디자인에 포함되어 외부 원본을 이동하거나 삭제한 후에도 복원합니다.

## 소스와 배포 구조

```text
프로젝트/
  assets/backgrounds/       내장 PNG 100장
  docs/BACKGROUND_GENERATION.json
  Backgrounds/             개발 실행용 개인 이미지, Git 제외

포터블 실행 폴더/
  jjal-generator-v3.0-portable.exe
  Backgrounds/             개인 이미지
```

내장 원본은 빌드 시 앱의 `resources/backgrounds`에 포함됩니다. 포터블 런처의 압축 해제 위치와 개인 폴더를 구분하며, 개인 폴더는 원래 EXE 위치의 `PORTABLE_EXECUTABLE_DIR`을 기준으로 찾습니다. 압축 해제형 배포에서는 앱 실행 파일 옆에 개인 폴더를 둡니다.

현재 목록에는 최대 2,000장, 파일당 64MB, 하위 5단계를 표시합니다. 썸네일은 3,200만 화소 이하를 지원합니다. 손상 이미지와 연결 폴더를 처리하며 앱에서 원본을 삭제하거나 수정하지 않습니다.

`BACKGROUND_GENERATION.json`에 실제 생성 프롬프트, 파일 이름, 원본 크기와 SHA-256을 기록했습니다. `배경_프리셋_100종.json`은 주제·색상·구도 목록입니다. 두 문서는 앱 인식에 필요한 등록 파일이 아닙니다. 세부 확인 범위는 [검증 기록](BACKGROUND_PRESETS_VALIDATION.md)에 있습니다.
