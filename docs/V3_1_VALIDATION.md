# 3.1.0 소스 검증

상태: **소스 수정과 개발 실행 검증 완료 / 사용자 최종 확인 대기**. 3.1 실행 파일을 빌드하지 않았고 커밋·푸시·GitHub 릴리스 갱신도 하지 않았습니다.

## 현재 기능

- 내용·규격 → 카드 팔레트: 배경 프리셋 둘러보기와 랜덤 배경 버튼. 랜덤은 내장 100장 전체에서 현재 이미지와 다른 배경을 즉시 선택합니다.
- 프리셋은 내장 배경만 제공합니다. 개인 폴더 선택·검색·감시 IPC를 제거했고 기존 개인 이미지와 설정 파일은 보존합니다.
- 배경·테두리 → 배경 이미지 넣기/제거: 기존 배경이 바뀐다는 확인 메시지. 취소하면 유지하며 문서 전환 중 늦게 도착한 선택도 차단합니다.
- 사양 패널 → 사양 글자: 항목명과 사양값의 외곽선 색·두께, 부드러운/네온 발광 색·범위·강도.
- 텍스트·요소: 추가 텍스트마다 같은 효과 제공. 가로·세로쓰기, 여러 줄, 그라디언트, 투명도, 기존 그림자와 함께 사용합니다.
- 내용·규격 → 사양 목록: 아이콘 크기를 0.5~2.5배 또는 8~96px로 조절. 픽셀 직접 지정은 글자 크기와 독립적입니다.
- 작은 창에서도 미리보기 가로세로 비율과 캔버스 영역을 일치시킵니다.

| 보존 | 생성 배경 100장·아이콘 시트 3장과 앱 아이콘 원본 해시 불변. 3.0 EXE·ZIP 해시 불변, 의존성 변경 없음 |

기본 사용자 저장소 대신 프로젝트 `work/v3.1.0` 아래의 `SPECCARD_USER_DATA`를 사용했습니다. 실제 실행 중인 3.0 앱과 사용자 디자인·개인 이미지는 수정하지 않았습니다. 네이티브 파일 대화상자의 반환값은 검증용으로 지정했으며 파일 읽기·저장·재실행은 실제 Electron API로 확인했습니다. 설정 화면 캡처용 Chrome에서는 파일 API를 미리보기 데이터로 대체했습니다.

## 자료와 다음 단계

소스 수정 전 복구본은 `work/v3.1.0/source-before-v3.1.0.zip`, 검증 결과는 같은 폴더의 `latest-ui.json`, `preview-verification.json`, `source-verification.json`에 있습니다. 원본 이미지는 `assets/backgrounds`와 `renderer/assets/spec-icons`에 유지합니다.
